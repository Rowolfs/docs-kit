# Фаза 2 — сайт и уровни чтения

<div class="lvl lvl-1" markdown>

## Обзор

**Фаза 2 реализована в demo и опубликована на GitHub Pages.** Сайт использует
бренд Quokki и показывает документацию в трёх накопительных уровнях: «Кратко»,
«Подробно», «Полностью». Читатель выбирает глубину нативным ползунком; выбор
запоминается и не мешает открывать прямые ссылки на подробные разделы.

Добавлены светлая и тёмная темы, поиск Zensical, доступное содержание страницы,
метрики слов и примерного чтения. Текст, код и Mermaid остаются в обычном
Markdown и локальных ассетах; сервер и LLM для сборки не нужны.

</div>

## Как устроено

Сборщик после рендеринга Zensical измеряет текст каждого блока `.lvl` и
добавляет метки в готовый HTML. Код, Mermaid, атрибуты, интерфейсные элементы
и URL ссылок в число слов не входят. Отдельный ползунок управляет накопительным
показом блоков. Счётчик в панели складывает слова видимых блоков и затем
оценивает чтение; исходная страница Markdown не меняется.

Прямые якоря и результаты поиска открывают нужный уровень на текущей странице,
не меняя сохранённый выбор. Содержание скрывает недоступные заголовки. Без
JavaScript все уровни и статические метки остаются в HTML. При печати CSS
показывает все уровни и скрывает интерактивные элементы.

Визуальный стиль живёт в `theme/assets/site.css`, логика уровней — в
`theme/assets/levels.js`, расчёт метрик — в `scripts/reading.py`. Zensical
обслуживает навигацию, поиск и базовую структуру темы.

## Детали

Ползунок имеет три целочисленных позиции 1–3 и доступное имя «Подробность»;
`aria-valuetext` сообщает выбранное значение. Переключение работает мышью,
перетаскиванием и клавиатурой. Настройка хранится в localStorage отдельно для
пути сайта проекта. Если браузер запрещает хранилище, интерфейс работает с
уровнем по умолчанию.

Поиск Zensical включает текст всех уровней. При переходе логика читает якорь
или параметр поискового URL и раскрывает цель до прокрутки. Старые якоря
главной и страницы сборщика сохранены. Mermaid скрипт и библиотека доставляются
из Pages, а ссылки в SVG уважают базовый URL репозитория.

Метрики считают Unicode-последовательности букв и чисел; внутренние дефисы,
апострофы и типографские варианты остаются частью слова. Число меньше скорости
чтения показывает «менее 1 минуты», более длинный текст округляется вверх.
Значение по умолчанию — 200 слов/мин; конфиг принимает 40–1000. Это оценка,
а не измеренная характеристика пользователя. Общий CI пока не проверяет лимиты
слов; такой docs-check относится к фазе 4.

### Проверка

- Zensical strict build: `make build`, `make demo`.
- 30 unit-тестов: сборщик и подсчёт текста; `make test`.
- YAML: `make lint-yaml`; GitHub Actions — actionlint 1.7.12.
- Браузерный demo в Chromium 142: ползунок и уровни, TOC, якоря, поиск,
  Mermaid, печать, темы, 320/390 px, отсутствие JS и запрет localStorage.
- Ошибок страницы, консоли, HTTP, внешних ассетов и неудачных сетевых запросов
  в браузерном прогоне нет.

### Не проверено

Не проводились сессии со screen reader, настоящий тест Find UI браузера,
проверка на физическом телефоне и тест понимания людьми за 1–2 минуты.
Браузерный тест `beforematch` вызывает событие напрямую. Полного аудита WCAG
и автоматической проверки лимитов текста пока нет.
