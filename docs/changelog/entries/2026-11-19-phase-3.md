# Модель и установка Quokki

## Что

Добавлены модель файлов, карта, SHA-ссылки и установка одной командой.

## Зачем

Дать агенту структуру проекта и правила сопровождения документации.

## Как работает

Git даёт пути, реестр задаёт компоненты, сборщик генерирует карту и JSON.
Установщик создаёт заготовки; агент пишет проверенные объяснения и запускает
доступные проверки до push. GitHub Actions собирает сайт.

## Затронуто

Генерация модели, сборка, тема навигации, bootstrap и инструкции агенту.

## Ограничения

Без символов, определения импортов и docs-check. Сборка журнала — фаза 5.

## Что проверить

Повторная установка, команды модели, размер JSON, ссылки с SHA и строгая сборка.
