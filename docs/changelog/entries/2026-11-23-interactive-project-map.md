# Интерактивная карта проекта

## Что

Карта получает интерактивную навигацию по компонентам, папкам и файлам.

## Зачем

Позволить человеку изучать структуру постепенно, сохраняя короткие объяснения
и связь с документацией компонента и конкретной версией исходного кода.

## Как работает

Cytoscape.js отрисовывает текущий уровень сгенерированной модели в браузере.
Индекс загружается первым, данные компонента — при переходе внутрь.
Путь над схемой возвращает к родителям, адрес сохраняет выбранный объект.
Список повторяет действия схемы для навигации клавиатурой.
Библиотека закреплена на точной версии и поставляется с сайтом локально.

## Затронуто

Генерация указателей на код, подготовка ассетов, генерируемая страница карты,
интерфейс и браузерные проверки demo. Установщик закреплён на новой версии
движка. Постоянно работающий сервер не появился.

## Ограничения

Связи берутся из `depends_on`, импорты и символы не анализируются.
Для незакоммиченного файла GitHub-ссылка отсутствует. Статическая диаграмма
и таблицы остаются доступны без интерактивного интерфейса.
Проверка экранным диктором и работа на очень больших репозиториях требуют
отдельной оценки. Docs-check относится к следующей фазе.

## Что проверить

Переходы узлами и списком, папки и файлы, возврат по пути и истории браузера,
сохранённый адрес, локальные ассеты, темы, мобильная ширина и статический режим.
Контрольная сумма библиотеки и отсутствие ссылок на незакоммиченные файлы
проверяются отдельно.
