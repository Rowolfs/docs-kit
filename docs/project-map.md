# Интерактивная карта проекта

<div class="lvl lvl-1" markdown>

## Кратко

[Открыть карту](./_generated/code-map.md), выбрать компонент и пройти внутрь:
компонент → папка → файл. Путь над схемой возвращает к любому родителю.

Ползунок **Кратко / Подробно / Полностью** управляет текстом страницы.
Карта раскрывается отдельно, поэтому краткое объяснение можно читать рядом
с подробной структурой кода.

</div>

<div class="lvl lvl-2" markdown>

## Подробно

На первом уровне показаны компоненты и объявленные связи `depends_on`.
Стрелка означает «использует». Внутри компонента видны его непосредственные
папки и файлы. Файлы вне реестра доступны отдельно; отсутствие принадлежности
не означает ошибку или неиспользуемый код.

Выберите узел схемы или соответствующий пункт списка под ней.
Список позволяет пройти тот же путь клавиатурой. У файла доступны его путь
и ссылка на GitHub с SHA сборки, если файл существует в этом коммите.
Страница компонента объясняет назначение и устройство кода.

Кнопки масштаба и вписывания помогают осмотреть схему. Адрес выбранного
объекта можно скопировать и открыть повторно. Карта загружает JSON компонента
при переходе внутрь; постоянно работающего сервера не требуется.

Если схема недоступна, ниже остаются таблицы и Mermaid-диаграмма.
Для таблицы файлов выберите уровень «Полностью». Без JavaScript весь
статический текст доступен сразу.

## Полностью

Источники карты — `components.yaml` и генерируемая модель уровня файлов.
Cytoscape.js отвечает за отрисовку в браузере; он не анализирует исходники.
Движок публикует точную версию библиотеки вместе с сайтом, проверяя контрольную
сумму при сборке. Посетителю не требуется обращаться к внешнему CDN.

При обновлении модели старый адрес удалённого объекта может перестать
разрешаться. Вернитесь к началу карты и выберите существующий компонент.
Ошибка получения JSON не меняет исходную документацию и не скрывает
статическое представление.

Карта не определяет зависимости из импортов и не показывает функции,
классы или фактический поток запросов. Связи достоверны настолько, насколько
проверен реестр. Состав файлов может включать незакоммиченные изменения;
для них ссылка на код не создаётся.

Вдохновение для навигации — [Ilograph](https://www.ilograph.com/).
Рендерер — [Cytoscape.js](https://js.cytoscape.org/), лицензия MIT.
Это отдельные продукты: код и закрытые возможности Ilograph не используются.
