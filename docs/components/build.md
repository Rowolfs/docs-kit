# Сборка документации

<div class="lvl lvl-1" markdown>

## Обзор

Сборщик превращает конфигурацию и Markdown проекта в статический сайт.
Он используется одинаково локально и в GitHub Actions, не меняя исходные
страницы. Постоянно работающего сервера нет.

[Вернуться на главную](../index.md).

</div>

<div class="lvl lvl-2" markdown="1">

## Как устроено

1. Прочитать `docs-kit.toml` и проверить расположение входных и выходных файлов.
2. Скопировать только `docs/` и ассеты движка во временный проект.
3. Получить закреплённый Mermaid, проверив SHA-256; повторно использовать
   корректный локальный кэш.
4. Сформировать внутреннюю конфигурацию Zensical и выполнить строгую сборку.
5. Перенести успешный результат в выходной каталог и записать сведения о версии
   движка и исходном коммите.

В CI reusable workflow отдельно получает проект и собственные исходники.
Для версии движка используются `job.workflow_repository` и `job.workflow_sha`,
относящиеся к вызываемому workflow. Значение `github.sha` используется
для исходников проекта и не подменяет версию движка.

При разрешённой публикации отдельный job получает готовый Pages-артефакт.
Публикация ограничена `main` и не выполняется для pull request.

## Детали

Исходники:
[build_site.py](https://github.com/Rowolfs/docs-kit/blob/main/scripts/build_site.py),
[build.yml](https://github.com/Rowolfs/docs-kit/blob/main/.github/workflows/build.yml).
Постоянные ссылки с хэшем будут генерироваться моделью в фазе 3.

Каталог `_docs_kit` зарезервирован под ассеты движка. Сборщик не поддерживает
символические ссылки внутри `docs/` и не заменяет произвольный существующий
каталог результата. Ошибка генератора сохраняет предыдущий готовый сайт.

Сведения о сборке находятся в `_docs_kit/build.json`: версия и SHA движка,
SHA исходного проекта, канонический URL. При локальных незакоммиченных
изменениях SHA обозначает базовый коммит, а не гарантию совпадения контента.
Это техническая информация для проверки версии, не модуль статистики.

Точный Python lock пока не содержит хэшей пакетов. GitHub.com поддерживается;
GitHub Enterprise Server без полей `job.workflow_*` пока не поддерживается:
workflow завершится ошибкой, не переключаясь молча на `main`.
