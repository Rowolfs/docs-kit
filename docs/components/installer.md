# Установка в репозиторий

<div class="lvl lvl-1" markdown>

## Кратко

Установщик создаёт реестр, Markdown-заготовки, конфиг и workflow в существующем
Git-репозитории. Он добавляет правила сопровождения в `AGENTS.md`. Назначение
компонентов не выдумывается: заготовки отмечены `planned`, агент заполняет их
после чтения кода. Установщик не запускает ИИ, не делает commit и push.

</div>

<div class="lvl lvl-2" markdown>

## Подробно

Bash-загрузчик получает закреплённую версию движка во временный каталог.
Python-скрипт группирует обнаруженные пути по верхним папкам, создаёт
идентификаторы компонентов и страницы с тремя уровнями. Зависимости изначально
пусты; их уточняет агент. Карта файлов генерируется из реестра автоматически.

Существующие инструкции сохраняются; блок Quokki имеет собственные маркеры.
Повторный запуск не заменяет авторские страницы. Конфликтующие существующие
файлы обнаруживаются до записи. Модель находится в игнорируемом `build/model/`.
Для запуска анализа тот же загрузчик принимает `--model` и команду модели.

</div>

## Полностью

Инструкция: [Подключение](../connect.md). Исходники: [install.sh](file:install.sh),
[install.py](file:scripts/install.py). Требуются Git, Bash, wget либо curl и Python с venv.
Первая установка и каждый вызов временного загрузчика требуют сети.
Публикация требует выбора GitHub Actions в Settings → Pages.

Правила агента: определить затронутые компоненты, прочитать код и diff, обновить
нужные блоки, указать статус и SHA проверки, запустить доступные проверки
документации и существующие проверки кода. После успешных проверок агент
отправляет изменения в рамках разрешения пользователя; Pages собирается в CI.
`docs-check` ещё не реализован: до фазы 4 инструкция явно требует ручной проверки
достоверности, ссылок и отсутствия секретов вместо фиктивного запуска линтера.

Существующая документация с конфликтующими именами требует явного объединения;
установщик не мигрирует произвольные генераторы. Шаблон проекта и окончательные
правила фазы 7 остаются отдельной задачей, базовая установка перенесена в фазу 3.

</div>
