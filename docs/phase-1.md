# Фаза 1 — каркас

<div class="lvl lvl-1" markdown>

## Обзор

Фаза 1 находится в работе. Подготовлены сборщик, общие ассеты, независимый
demo и workflows. Результаты локальной и удалённой проверки будут записаны
здесь после фактического выполнения. Фаза 2 не начата.

</div>

<div class="lvl lvl-2" markdown="1">

## Как устроено

Сборщик читает тонкий конфиг и Markdown, создаёт временный проект и вызывает
Zensical. Reusable workflow использует собственный SHA для движка и отдельно
получает исходники вызывающего проекта. Публикация получает готовый артефакт.

Сам docs-kit и независимый demo используют один и тот же Python-сборщик.
Эксперимент фазы 0 сохранён без изменения его назначения.

</div>
